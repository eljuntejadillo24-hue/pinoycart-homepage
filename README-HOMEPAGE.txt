PinoyCart Customer Homepage package

This ZIP contains the customer storefront only: product listing, product details, cart/checkout assets.

Backend/API files are NOT included. Keep the existing backend running and configure/verify its API endpoints before publishing.
The storefront currently calls /api/products/pancake and expects the website/backend to serve the API.

Deploy this folder as a separate static website. Do not upload admin.html or admin.js here.
